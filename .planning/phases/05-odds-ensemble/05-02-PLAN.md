<objective>
Build `engine/backsolve.py` and FILL the two pre-cut engine stubs that Phase 1 cut for exactly
this purpose — additively, so the GATE-01 Budapest backtest stays green. Three jobs:

1. **Series->map invert + logistic ratings fit** (D5/ODDS-04, Pitfall 9): `invert_series`
   recovers the per-map `p` from a series prob — identity for Bo1, **bisection-invert `p²(3−2p)`**
   for Bo3 (`0.648 -> 0.6`). Then `fit_ratings` is a hand-rolled numpy-only Gauss-Newton logistic
   least-squares fit of per-team ratings to the MAP-level targets, with one **anchored gauge team**
   removing the additive `(r+c)` null space. NO scipy (stack constraint). Fitting ratings to
   *series* probs (without inverting first) conflates Bo1 and Bo3 so one rating can't price both
   unplayed branches — invert FIRST.

2. **Market override for the imminent round** (D5/ODDS-04, PROB-02): the back-solved ratings
   reprice ALL unplayed branches, but for the next round's KNOWN matchups the market series prob
   is injected DIRECTLY via a NEW keyword-only `market_overrides` arg threaded
   `simulate_stage -> _play`, mirroring how `locked` flows. The stored override `p` is
   **P(lower-id team wins)**, but `_play` receives its pair in **difficulty-ranked (high, low)
   order** from `pair_within_group` — so `_play` MUST orient the prob to the lower-id team (look up
   by an id-keyed bucket, compute `p_a = p if a.id < b.id else 1 - p`) before drawing, or it
   silently inverts the favorite on half the matchups. `engine.probs.series_prob` already
   short-circuits on `market_series_prob` and does NOT re-apply Bo3 — CALL it; default
   `market_overrides=None` = no behavior change.

3. **Fill the epistemic OUTER loop** (D6/PROB-03/04/05): `epistemic_draws` yields K
   `rng.beta(*beta_moment_fit(mean, v))` per-element draws — but `k=1` with all-zero `var` (or
   `rng=None`) preserves the Phase-1 single-point no-op EXACTLY (the rating-only path must be
   byte-identical so GATE-01 stays green). The drawn `_p_vec` (currently discarded in
   `run_mc_progressive`) feeds the inner sim as that outer draw's `market_overrides`; per-team
   counts aggregate ACROSS the K draws so the reported band ⊇ the inner Wilson band and does NOT
   shrink with N on a high-disagreement match (the epistemic spread is the across-draw spread, not
   the inner aleatoric Wilson term). The `var < mean·(1−mean)` clamp is the EXISTING
   `beta_moment_fit` (probs.py:92, verified correct) — CALL it, never re-implement (Pitfall 5).
