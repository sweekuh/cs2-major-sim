<objective>
Build the pure odds core — the `odds/` package — with ZERO engine or app mutation. It owns the
three pitfall-fatal pieces of the ensemble math, all referentially transparent and fully
TDD-able against recorded JSON fixtures (no live network, because Cologne markets are not posted
on 2026-05-29):

1. **De-vig routed on `vig_type`** (D3/ODDS-02): `devig_fixed_two_way` for OddsPapi fixed odds
   (`(1/o_a)/(1/o_a+1/o_b)`, the `1.5/2.5 -> 0.625` check); `normalize_market_price` for the
   prediction markets (price ≈ prob, spread/fee only). Applying the two-way de-vig to a market
   price is a silent corruption (Pitfall 8) — there is no second decimal-odds side.
2. **The OddsPapi soft-book bundle pre-pooled to ONE Pinnacle-anchored opinion** (D4/ODDS-03,
   Pitfall 7) — inside `odds/oddspapi.py`, BEFORE `pool()` sees it, so the cross-provider pool
   never headcounts the soft books that copy Pinnacle's line.
3. **The log-opinion pool** (D4/ODDS-03): a liquidity/originate-weighted geometric mean in logit
   space emitting `BlendedProb(p, var, n_sources, bo3)`, where `var` is the cross-source
   (epistemic) spread. Agreeing sources -> `var≈0` (band collapses to the inner Wilson, PROB-05);
   a single source -> `var≈0`.

The headline fail-soft fact (D3, new this phase): Polymarket and Kalshi public market data are
**keyless** public reads, so "no key" still yields a 2-source pool — the `ODDSPAPI_KEY` only
unlocks the Pinnacle anchor. The adapters are built + unit-tested entirely against recorded
fixtures; live slug/ticker confirmation is deferred to 05-03's user checkpoint.

`httpx`/`dotenv` live ONLY inside `odds/` (and `scripts/` in 05-03) — `odds/base.py` and `pool()`
are pure numpy, and nothing in this plan is reachable from the app import path (DX-01 preserved).

Authored TDD (RED test task -> GREEN impl tasks) mirroring the Phase 1/3/4 correctness-core-first
discipline: the pitfall-fatal math (de-vig routing, bundle-as-one-opinion, pool variance) is
provable in `pytest` before any I/O or UI exists.

Output: `odds/{base,oddspapi,polymarket,kalshi}.py` + `odds/__init__.py`, `tests/test_odds.py`,
and the recorded `tests/fixtures/*.json`.
</objective>

| per-source p_a_raw -> pool() | De-vigged/normalized probs combined; raw `var` emitted for the downstream beta_moment_fit clamp — never pre-clamped here |
