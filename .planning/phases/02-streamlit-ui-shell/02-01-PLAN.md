<objective>
Deliver the thinnest runnable end-to-end UI slice: a fresh clone can run `uv run streamlit run app.py`, click Run with the shipped default ratings (no API key, no editing), watch a real progress bar driven by the engine generator, and see per-team P(advance)/P(3-0)/P(0-3). Purpose: This is the vertical foundation every later Phase 2 slice extends. After this plan a real user can do something they could not before: get honest per-team probabilities from the proven engine through a browser. Plan 02 layers the two-mode shell + visual tokens on top; plan 03 layers trust/seed/DX docs.

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| user (data_editor / sliders) → app.py | Untrusted rating/S/N input crosses into the engine call |
| app.py → st.markdown(unsafe_allow_html=True) | App-generated HTML rendered in the browser |
| data/stage1.json → load_teams() | Local JSON parsed at startup (read-only) |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-INPUT | Tampering/DoS | rating cells / N input → engine | mitigate | validate_ratings blocks empty/out-of-range before the engine is called (UI-05); N capped via st.number_input max_value mirroring the engine 5M cap; engine _validate_fixture is defense-in-depth |
| T-02-XSS | Tampering | ci_bar_html via unsafe_allow_html | mitigate | CI-bar HTML is built from numeric floats only; team names / any user free-text are NEVER interpolated into the HTML markup (RESEARCH Security Domain) |
| T-02-JSON | Tampering | data/stage1.json parse | accept | load_teams() already validates the fixture loudly (16 unique seeds, finite in-range ratings) and falls back to in-code defaults; local single-user file, low risk |
| T-02-SC | Tampering | `uv sync` adding streamlit | accept | streamlit is the canonical CLAUDE.md-mandated package, Approved in RESEARCH Package Legitimacy Audit (~6yr, ~5M/wk, github.com/streamlit/streamlit); no [ASSUMED]/[SUS] package introduced |
