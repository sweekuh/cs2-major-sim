Drop the IEM trophy photo here as:

    iem-trophy.jpg

The hero (top-right of public/index.html) loads `assets/iem-trophy.jpg`.
If the file is missing, the frame hides itself gracefully (no broken-image icon) —
so the page stays clean until you add it. Save the ESL/IEM press photo you have
to this folder with that exact filename and reload.

Recommended: a landscape (~16:9 or 3:2) JPEG, ~1200px wide is plenty.
